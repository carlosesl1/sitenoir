# Service project pages

Scope: the nine published `/services/[slug]` pages, extending the established NOIR identity. The visitor is evaluating a service through work already delivered. Mode: Experience, followed by a conversation about a similar project.

The work leads. Replace the undersized project images and long empty openings with a compact introduction and a generous visual canvas. Website cases read as a design portfolio, video cases as a screening room, and Google cases as a journey from discovery to decision. Keep the real project content, images, credits, native video controls, captions, contact preselection, and Portuguese/English behavior.

The first viewport pairs a readable headline with concise project context and the start of the actual work. A direct anchor reaches the interface, films, or profile evidence. Body copy uses the existing display sans; the existing mono is reserved for navigation and project metadata. Neutral surfaces inherit both themes. Client colors live in imagery and small structural accents, never in low-contrast body text.

The scroll alternates generous imagery with shorter editorial passages. The final contact invitation is open typography rather than a decorated card, followed by a visual preview of the next project. Preserve the homepage and global design system.

Verification: all nine routes at desktop/mobile widths in PT/EN, representative screenshots for each template, light theme, keyboard focus, anchors, video controls/captions, and contact/navigation destinations. No fabricated results, no new dependencies, no publication in this scope.
